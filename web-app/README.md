# ZAVOD — Script to Set

Սցենարից նկարահանման պատրաստ աշխատանքային փաթեթ ստեղծող տեղային գործիք։

## Գործարկում

```bash
cd /Users/apple/zavod-om/web-app
npm start
```

Բացել՝ [http://localhost:4173](http://localhost:4173)

## Ինչ է աշխատում

- հայերեն, ռուսերեն և անգլերեն միջերես,
- PDF, TXT և Fountain ներմուծում,
- լոգլայնի, սինոփսիսի և սցենարի առանձին ռեժիմներ,
- տեսարանների, հերոսների, վայրերի և արտադրական տարրերի ճանաչում,
- խմբագրվող տեսարանային վերլուծություն, հաստատման կարգավիճակ և CSV արտահանում,
- խմբագրվող նկարահանման ժամանակացույց՝ տեսարանները օրերի միջև տեղափոխելու հնարավորությամբ,
- յուրաքանչյուր տեսարանի պահպանվող կադրապլան և սթորիբորդի սևագիր,
- փոփոխություններից հետո հնացած արդյունքների տեսանելի նշում,
- նկարահանման օրվա փաթեթ՝ կանչի ժամով, կազմով, վայրերով, տարրերով ու ռիսկերով,
- վեց սլայդից կազմված HTML փիչ-դեք,
- օրվա փաթեթի HTML և նախագծի ամբողջական JSON արտահանում,
- վերջին նախագծի տեղային պահպանում ու շարունակություն։

PDF-ը մշակվում է միայն տեղային համակարգչում և բնօրինակ ֆայլը չի պահպանվում։ Սկանավորված PDF-ի համար OCR դեռ չկա։ Վերլուծությունը, գրաֆիկը և կադրապլանը աշխատանքային սևագրեր են և պահանջում են համապատասխան մասնագետի հաստատումը։
