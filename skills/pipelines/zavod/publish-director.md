# Publish Director — ZavodOM

## When to use
Package the finished deliverable for posting: caption, hashtags, metadata, schedule, AI-content label.

## Craft (read from skills/zavod-craft/)
`playbook.md` (captions, hashtags ≤5, posting time, algorithm, format split),
`growth-analytics.md` (Trial Reels A/B, first-hour velocity, weekly metrics → content decisions).

## Process
1. Write caption (SEO keywords in first 2 sentences) + ≤5 hashtags (3-5 in caption).
2. Add posting note (window, first-hour action) and the per-platform AI-content label (TikTok C2PA).
3. For multi-deliverable, order/number for the posting schedule.

## Produces
`publish_log`.

## Gate
Reviewer: caption voice (brand-voice.md), hashtag cap, AI-label present. Glyph gate on Armenian caption.
Human checkpoint before anything actually publishes.
