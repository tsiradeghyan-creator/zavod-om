# Playbook — Posting, Captions & Algorithm (2026)

Distilled from the agency's `long-term-memory.md` research. Apply at Stations 3–4.
Re-check long-term-memory periodically; algorithms shift.

## Format strategy
- **Reels = REACH** (3–5× reach via Explore/Reels feed) → stranger discovery.
- **Carousels = CONVERSION** (~10% engagement; **~22% more saves than single photos,
  ~2× the saves of Reels**) → stranger → follower → client.
- One asset should not serve both jobs. Cadence: **2–3 Reels/week + 1–2 carousels/week.**

## Carousel rules (recap; full recipe in `carousel-template.md`)
- Slide 1 = ~80% of weight (0.25s window). **Slide 2 must also work as a standalone
  alternate hook** (second-chance delivery re-serves starting from slide 2). Slide 3 =
  swipe checkpoint.
- **6–10 slides** optimum; long form (13–15, max 20) only for true serial breakdowns.
- ≥1 save-worthy slide. High-swipe carousels get re-served 24–48h later.

## Hook gate (absorbed from МЕТАФЛОРА Claudebook, 2026-07-04)
Before a hook ships (Reel opener, carousel slide 1, caption first line), run 10 candidates
through a 4-check gate — a table, not a vibe:

| Check | Pass condition |
|---|---|
| **Read speed** | հասկացվում է ≤2 վրկ (slide-1 = 0.25s window, `carousel-template.md`) |
| **Concrete promise** | խոստումը կոնկրետ է, ոչ ընդհանուր («ինչպես» + որոշակի արդյունք) |
| **No clickbait lie** | վերնագիրը չի խաբում — բովանդակությունը կատարում է խոստումը |
| **Named pain** | թիրախ-ցավը անվանված է (comment-mining-ից, `idea-lab.md`) |
Output: top-3 hooks, one sentence each on WHY. Ties into Trial-Reels A/B engine below.

## Reel rules
- **Hook in first 3 seconds** (50–60% drop-off there). Strongest visual on frame 1.
- **Jump-cut every 3–5 seconds** (~32% higher engagement than continuous shot).
- **Burned-in captions** (Armenian + thin English underbar) — +15–25% retention. Not auto-CC.
- Length: Reels target 30–60s; Shorts ≤3 min; TikTok target 21–34s (`post-production.md` specs).
- **Ani's face-to-camera leads; AI footage = b-roll/teaser support.** This is on MERIT, not
  a penalty: Meta says creation method doesn't change distribution; human-fronted simply
  performs better. **Label AI video** — TikTok requires C2PA labels (unlabeled realistic AI
  is a strike risk; ~5–8% reach dip when labeled).
- **No other-app watermarks** (TikTok logo demotes the whole Reel on IG).
- For "retention loop" Shorts: end cliffhanger flows back into the opening visual.

## Captions
- Follow the `style-profile.md` formula (hook → truth → numbers → comment CTA).
- **Caption-SEO**, not hashtag spray: weave real search phrases in ("հայկական դրամա սցենար",
  "Armenian screenwriter", show name) **in the first two sentences**; keyword the bio/handle;
  fill **alt text**. Caption SEO out-ranks hashtags in 2026.
- **Topic clarity** so IG files the post under the right "Your Algorithm" topic.

## Hashtags
- **Max 5** (Dec 2025 hard cap) — and the cap counts **caption + comments COMBINED**, so the
  old "put them in the first comment" trick buys nothing. Put **3–5 in the caption**.
- Armenian, keyword-aligned; 1–2 can be geo-tags for diaspora.

## Posting & first hour (the velocity gate)
- **No fixed "% of followers" test** (that's a debunked myth). IG runs a staged **audition
  system**: a small **non-follower** seed group first, expanding as the post performs. Early
  velocity (saves+shares+DM-sends+comments per minute) still decides escape to Explore/Reels.
- **Action on every drop:** immediately DM/share the link to a close circle (8–12 people /
  a Telegram private group) to spike first-hour velocity.
- **DM sends + saves + shares >> likes** as ranking signals.
- **Diaspora gold window (Yerevan time): 19:00–21:00** = 08:00–10:00 LA + 18:00–20:00 Moscow —
  serves both diaspora hubs at once. Consistency + audience-active windows beat clock
  superstition; validate per post (`growth-analytics.md`).

## Growth surfaces (open these — details in `growth-analytics.md`)
- **Trial Reels** (3–5/week to non-followers, 72h window, zero profile risk) = the A/B
  hook-testing engine.
- **Broadcast channel NOW** (no follower minimum, weekly cadence) — a loyalty signal.
- **Comment-keyword → auto-DM funnel** (ManyChat-class): DM sends are a top signal AND
  convert carousel viewers to leads.
- **Pinned 3-post architecture:** intro/positioning + best converter + current series.
- **Collab posts** with Armenian culture/meme/diaspora pages (doubles reach into LA/Moscow).
- **IG Notes**, **YouTube Shorts** (≤3 min, retention loop), and **Telegram-native** growth
  (folder cross-promo packs, forward-from-channel CTA, premium emoji / Stars).

## Cross-platform (one source, native per platform)
- IG carousel → TikTok photo-collage (native, not screenshot dump) → Threads thread.
- Don't repost identical; adapt format per platform. Avoid foreign-app watermarks.

## Monetization layers (later)

- Vertical micro-drama (ReelShort/DramaBox/TikTok "Mini Drama") = the agency's natural format
  for the «Վանը»/«Ախրիման» universe — **60–100×1–2min** episodes, AI-prototyped cheaply
  (`producer-craft.md` economics · `serial-structure.md` beat math).
