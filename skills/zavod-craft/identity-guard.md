# Identity Guard — Պրեմիում ինքնության և վեկտորային արվեստի դարպաս

The agency's visual face must read **premium, powerful, confident** — never cheap or
"default AI". Video/photo engines are great at scenes but drift toward amateur solutions on
logos, wordmarks, and graphic design. This station's only job: gate typography / vector art /
logos, and ship print-ready **SVG**. Brand facts: `maghakian-brand`. Motion type: `motion-design.md`.

## The iron gate (reject anything that isn't premium)

A design ships ONLY if it passes all four — otherwise it's rejected, not "tweaked":
- **Confidence:** does it command the frame? Editorial weight, decisive contrast, no timid
  centering-for-safety. If it whispers, it fails.
- **Restraint-not-cheap:** premium = disciplined, not loud-busy. One idea, perfect execution
  (`brand-voice.md` confident-not-loud). No gradient-soup, no stock-AI sheen, no bevels/drop-glow.
- **Brand-true:** palette black #0D0D0D / purple #6450D2 accent / gold; Armenian in proper
  Unicode; type from the approved stack (`motion-design.md`). Purple is accent, never a wash.
- **Reproducible:** works at 16px favicon AND on a building. If it dies when scaled, it fails.

## Engines & output

- **Vector-native generators:** Recraft (true SVG), Ideogram 4.0 (logo/text), Illustrator
  image-trace as fallback. Never a video/photo engine for a logo concept.
- **Always export SVG** (plus 1× PNG preview) — print, embroidery, signage, app icon, favicon.
  Raster-only logos are rejected; branding needs vectors.
- Keep a master `brand/` folder: `logo.svg`, `wordmark-hy.svg`, `wordmark-en.svg`, mono/inverse
  variants, clear-space + min-size spec.

## Logo / wordmark discipline

- **Armenian wordmark first** (the agency is Armenian); Latin wordmark as the diaspora variant.
- Mono + inverse + one-colour versions mandatory (pairs with `color-craft.md` monochrome protocol).
- Clear space = cap-height all around; min size logged; never re-proportion or recolour off-spec.

## Identity-Guard checklist
- [ ] Passes all four gates (confidence · restraint-not-cheap · brand-true · reproducible).
- [ ] SVG exported + PNG preview; mono/inverse variants present.
- [ ] Armenian Unicode clean (glyph gate, `motion-design.md`); approved type only.
- [ ] Works at favicon and billboard scale; clear-space + min-size documented.
- [ ] No video/photo-engine output used for a logo/wordmark.
