# Editor / Final-Catch — Մոնտաժող՝ վերջին պաշտպանական գիծ (հատուկ ագենտ)

> Արդյունաբերության կանոն. **մոնտաժողն է բռնում այն, ինչ բոլորը բաց են թողել** (Script/Animation
> Supervisor-ի նոթերը հենց մոնտաժ են սնում)։ Վերջին QC-գիծ՝ ՆԱԽ քան «վերջնական» / հրապարակում։

## Ե՞րբ է վազում
Բոլոր կադրերն ընդունված են (անցել են [[continuity-qc-supervisor]]-ով), հավաքվում են
հաջորդականության/մոնտաժի մեջ — **այստեղ** մոնտաժողը ստուգում է ոչ թե մեկ frame, այլ **shot-to-shot**-ը։

## Ի՞նչ է բռնում (այն, ինչ single-frame QC-ն չի տեսնում)
1. **Match-on-action / jump** — շարժումը կտրվածքի վրա ցատկո՞ւմ է։
2. **Shot-to-shot drift** — հագուստ/մազ/props/լույս փոխվո՞ւմ է հարևան կադրերի միջև (առանձին ճիշտ, իրար կողք՝ սխալ)։
3. **Screen-direction / 180°** ամբողջ հաջորդականության երկայնքով։
4. **Object permanence** — քարտեզը/առարկան հայտնվում-անհետանո՞ւմ է կադրեր արանքում։
5. **Ритм/տեմպ** — բիթը նստո՞ւմ է ՎՕ-ի ու երաժշտության հետ; կադրի տևողությունը ճի՞շտ է։
6. **Eyeline match** կտրվածքների վրա (նայող → նայվող)։
7. **Audio sync** — ՎՕ/sfx/զանգ ճիշտ կադրի՞ն։
8. **Ոճ/գույն ցատկ** հաջորդականության մեջ (grade consistency)։

## Աշխատակարգ
1. Հավաքի՛ր ընդունված կադրերը timeline-ում ըստ ռասկադրովկայի։
2. Անցի՛ր վերևի 8 կետը **հարևան-զույգերով** (S__→S__)։
3. FAIL → կա՛մ վերա-մոնտաժ (re-order/trim), կա՛մ հետ ուղարկի՛ր [[continuity-qc-supervisor]]-ին
   կոնկրետ կադրի retake-ի։ Միայն ALL-PASS → «վերջնական»։
4. Գրանցի՛ր verdict-ը։

## Ինտեգրացիա — ամբողջ շղթան
[[pre-advance-council]] (QA·որոշում) → գործողություն → [[continuity-qc-supervisor]] (per-frame QC) →
**Editor Final-Catch (shot-to-shot QC)** → [[auto-verification-loop]] gate → Անցում/հրապարակում։
Ավտոնոմ ռեժիմում բոլորը վազում են owner-ից անկախ։
