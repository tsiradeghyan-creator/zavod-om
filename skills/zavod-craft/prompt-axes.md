# Prompt Axes — the AI-frame menu (Composition × Lighting × Pose)

A fast **controlled vocabulary** for building any AI image/video prompt line. This is NOT
craft theory — the depth lives in `cinematography.md` (light), `color-craft.md` (grade),
`storyboard.md` (the shot card) and `director-craft.md` (blocking). This file is the **lookup**:
pick ONE from each axis, drop the phrase into the prompt, and you never forget an axis or
default to the same boring frame. Built from three reference cheat-sheets ingested 2026-06-27.

## The builder (one line per frame)
`[shot size] + [composition] + [lighting] + [pose/action] + [lens mm + move] + house grade + guardrails`
- **House grade** = the show LUT (e.g. warm Kodak Portra, fine grain, no blown whites).
- **Guardrails** (always): Maghakian AI frames → **no actor face** (hands/back/silhouette/object);
  desert-owl & lifestyle → generic faces OK. Vertical 9:16 → subject + subtext object in middle 65%.
  Restraint default: when unsure, wider · longer · stiller. **No AI text inside the frame.**

## Notes
- **Variety rule:** across a 5-cut board, never repeat the same composition+pose pair — rotate axes.
- **Maghakian reminder:** pose = behaviour over the shield (cooking, pottery); board the hands,
  not the face; the prop-pose IS the subtext object (`art-department.md`).
