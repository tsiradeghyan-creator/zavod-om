# Editorial — design_styles

- id: editorial
- essence: magazine-rooted layout discipline — the word is the hero, set with taste.
- signature markers: strict grid + generous whitespace, serif display + clean grotesk body hierarchy, pull-quotes, asymmetric balance, baseline rhythm, restrained palette, considered margins.
- AI / CSS keywords: "editorial magazine layout, strong type hierarchy, asymmetric grid, generous whitespace, pull quote" · type pairing: editorial serif (e.g. Fraunces) + grotesk (e.g. Inter).
- when to use: the agency's default voice — Maghakian IS a script/writing agency, so text-forward editorial is the spine; long-form carousels, manifestos, quote series.
- Maghakian application: her aphorisms («Չկա-ն սարսափելի բառ է») set as editorial pull-quotes over negative space; serif carries gravity, grotesk carries the label/CTA. Armenian type via brand font overlay.
- anti-pattern: centered-everything + no hierarchy = brochure, not editorial; decorative type for body; cramped margins.
- reference: Kinfolk / It's Nice That / Pentagram editorial systems.
