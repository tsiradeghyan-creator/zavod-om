# Technical Mono (developer-culture aesthetic) — design_styles

- id: technical_mono
- essence: monospace type as a design voice — futuristic-yet-raw, anti-glossy, engineering-honest.
- signature markers: monospace type for labels/credits/CTA, terminal/code cues, tight grid, muted palette + exactly 1 signal color, no gradients, generous label tracking.
- AI / CSS keywords / grade: "monospace label, terminal-style caption, tight grid layout, muted palette with single accent color, flat no-gradient surfaces" · CSS: `font-family: ui-monospace/SF Mono; letter-spacing: 0.08em; text-transform: uppercase`.
- when to use: label/credit/CTA layer over photography; process/behind-the-scenes content; anything that should read current, restrained, agency-smart.
- Maghakian application: pairs with the editorial spine — mono labels/credits/CTA over photography; Armenian display text stays brand-font overlay (mono is for the Latin/label layer, never a substitute for brand Armenian type).
- anti-pattern: mono for body text at length (unreadable); cosplaying a code editor instead of using mono as accent; more than one signal color.
- reference: developer-culture editorial (It's Nice That 2026); terminal UI restraint.
- wiring: label/credit treatment in editorial + asset-director. Approved 2026-07-02 (owner) via Style Radar memo 06-25.
