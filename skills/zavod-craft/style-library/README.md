# Style Library — matured taste cards

Cards graduate here from `../style-radar.md` once approved. One file per style/reference.
Driven by `library/style_radar.json` (registry) + `lib/style_radar.py` (gated Scout twin).

## Card schema (keep every card to this shape)
```
# <Name> — <axis>
- id: <matches style_radar.json>
- essence: one line, what it IS
- signature markers: the concrete, recognisable cues (palette / type / material / shape / light)
- AI / CSS keywords: prompt-ready phrases that produce it
- when to use: which register / surface / moment
- Maghakian application: how it serves HER world (object/silhouette/register), never generic
- anti-pattern: how it goes wrong / the cheap-knockoff tell to reject
- reference: 1 named anchor (artist / film / brand / foundry)
```
