# Neobrutalism — design_styles

- id: neobrutalism
- essence: deliberately "raw" graphic style — structure shown, polish refused.
- signature markers: hard 2-4px black borders, **solid offset drop-shadow (no blur)**, clashing saturated colors, mono/system or grotesk type, zero gradients, sticker-like elements, high contrast, visible grid.
- AI / CSS keywords: "bold black outline, hard offset shadow, flat saturated color blocks, no gradient, raw grid" · CSS: `border: 3px solid #000; box-shadow: 6px 6px 0 #000;`
- when to use: edgy/youth posts, announcement graphics, A3 comedy register, attention-grab carousels.
- Maghakian application: loud announcement/quote cards in the comedy/satire register (Սոսկալի); pair with one show accent so it stays branded, not generic Gumroad-clone.
- anti-pattern: soft/blurred shadow or a gradient = instantly breaks brutalism; "neobrutalism + pastel minimalism" is a contradiction — pick one.
- reference: Gumroad redesign era / Figma neobrutalist wave.
