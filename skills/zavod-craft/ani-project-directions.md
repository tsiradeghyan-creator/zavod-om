# Անիի նոր նախագծային ուղղություններ

Այս ֆայլը պահում է միայն սեփականատիրոջ հստակ հաստատած՝ նախագծին հատուկ ուղղությունները։ Նոր ուղղությունն անմիջապես կիրառելի է այդ նախագծում, բայց անցյալի հեղինակային ձեռագրի ապացույց չէ։

## Գրանցման ձև

- Ամսաթիվ / աղբյուր՝
- Նախագիծ / տարբերակ՝
- Սեփականատիրոջ ուղիղ ուղղությունը՝
- Շրջանակը՝ (մեկ տեսարան / մեկ աշխատանք / շարքի շարունակություն / բոլոր նախագծեր՝ միայն եթե հստակ ասված է)
- Փոխարինում կամ հակասություն՝
- Հաստատման մեջբերում կամ հղում՝

## Արդեն հաստատված աշխատանքային ուղղություն

- Ամսաթիվ / աղբյուր՝ 2026-09-29, սեփականատիրոջ ուղիղ հանձնարարություն։
- Նախագիծ / տարբերակ՝ Անիի սցենարային գործակալների համակարգը՝ համընդհանուր workflow։
- Ուղղությունը՝ կարդալ Անիի սցենարներն ու սովորել գրելու «անատոմիան»․ գործակալներին շարունակաբար կատարելագործել, որպեսզի նոր տեքստեր, սցենարներ և նոր ուղղություններ տրամադրելիս պրոֆիլը թարմացվի։
- Շրջանակը՝ բոլոր սցենարային գործակալների ուսուցման/թարմացման ընթացակարգը։ Յուրաքանչյուր նոր ստեղծագործական ուղղության բովանդակային շրջանակը մնում է կոնկրետ նախագծային, եթե սեփականատերը հստակ չի ասում, որ այն համընդհանուր է։
- Սա workflow-ի մասին ուղղություն է, ոչ թե Անիի նախկին ձեռագրի կամ նոր ժանրային նախասիրության ապացույց։

«Մոռացողը» և «Առասպել» ընթացիկ նյութերն օգտագործվել են որպես համեմատական նախագիծ/ուղղություն, ոչ որպես պատմական ձեռագրի ապացույց։
