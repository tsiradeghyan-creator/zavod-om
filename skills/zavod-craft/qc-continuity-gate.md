# QC Continuity Gate — Շարունակականության դատարան և դարպաս (FILM MODE, պարտադիր)

> Ծնվել է 2026-06-14-ի «Վան» նախագծի արատից (Վանը կրկնված, ուսուցիչը անկայուն)։
> Ոչ մի կադր/frame չի անցնում «ընդունված» կարգավիճակի առանց այս դարպասը անցնելու։
> Պատասխանատվությունը կպչում է ԿԱՅԱՆԻՆ, ոչ թե ընդհանուր համակարգին։

## Պատասխանատվության մատրից (ո՞վ ինչի՞ համար է պատասխան տալիս)

| Արատ | Պատասխանատու կայան/ագենտ | Վերահսկողություն, որ պետք է աշխատեր |
|---|---|---|
| Կրկնված կերպար մի կադրում | **AI-Pipeline (ռենդեր)** | «single-instance» կանոն + դատարկ-plate; լիքը master-ից reframe ԱՐԳԵԼՎԱԾ Է |
| Դեմքի/հագուստի drift (հերոս կամ էքստրա) | **Script Supervisor / Continuity** (`production-team.md`) | frame-առ-frame continuity ledger; կանոնական դեմք-պորտրետ |
| Կադրը չի համապատասխանում սցենարի բիթին | **Storyboard artist** (`storyboard.md`) | բիթ↔frame համեմատում |
| Արատավոր take-ը ընդունվել է | **Ռեժիսոր** (`director-craft.md`) | select/retake rejection criteria, վերջնական ստորագրություն |
| Արատավորը հասել է սեփականատիրոջը | **Co-Producer / Protocol** (`production-protocol.md`) | QC-line Agent Report-ում |

## Rejection criteria (ավտոմատ մերժում — retake, ոչ reroll)
1. **Կրկնված կերպար** — նույն հերոսը >1 անգամ կադրում։
2. **Դեմք-drift** — հերոս կամ կարևոր էքստրա (ուսուցիչ) ≠ կանոնական պորտրետ։
3. **Պատահական/սխալ դեմք**, palette drift, սխալ action-verb։
4. **Բիթ-անհամապատասխանություն** սցենարի հետ։
5. **Շարունակականություն** — eyeline, screen-direction, հագուստ, ռակուրս։

## Per-frame Continuity Ledger (ստորագրվում է ԱՄԵՆ frame-ի համար ընդունելուց առաջ)
```
Frame S__ :
[ ] Կրկնված կերպար ՉԿԱ (ամեն հերոս ուղիղ 1 անգամ)
[ ] Բոլոր դեմքերը = կանոնական պորտրետ (հերոս + էքստրա)
[ ] Հագուստ/ռակուրս/eyeline = master-ին համահունչ
[ ] Համապատասխանում է սցենարի տվյալ բիթին
[ ] Հայերեն տեքստ ՀՈՒՄ AI-կադրում չկա (բացառություն՝ glyph-gate անցած ԿԱՐՃ display բառ)
Ստորագրություն՝ Continuity ✍  ·  Ռեժիսոր ✍
```
**Տեքստի կանոնի սահմանը (ոչ թե հակասություն).** Այս ստուգումը վերաբերում է ՄԻԱՅՆ հում
AI-ռենդերին։ Compositor-ի / carousel workflow-ի / motion-design-ի ավելացրած overlay
տիտրերն ու ենթագրերը ՊԱՐՏԱԴԻՐ են ու օրինական — դրանք ստուգվում են glyph gate + ուղղագրությամբ
(`motion-design.md`), ոչ թե այս կետով։ Body text-ը AI-ի մեջ երբեք չի «թխվում»։

## Արգելված մեթոդ (պատճառ #1 արմատը)
**Մի՛ reframe արա լիքը (բնակեցված) master-ից** — մոդելը պահում է հին կերպարը + ավելացնում նորը = կրկնակ։
**Ճիշտ մեթոդ.** (ա) դատարկ-դասարան plate (առանց աշակերտների) = կողպված ֆոն; (բ) ամեն կերպար դնում ենք գիտակցաբար **մեկ անգամ**, prompt-ում՝ «only ONE [character]; no duplicate»; (գ) կանոնական դեմք-պորտրետ՝ գլխավոր ռեֆերանս; (դ) կարևոր էքստրաները (ուսուցիչ) composite կամ հետևողական շրջանակ։

## Դարպասի օրենք (governance)
Agent Report-ը `production-protocol.md`-ում ստանում է նոր պարտադիր տող՝
**`QC-Continuity: PASS/FAIL (ledger կցված)`** — FAIL-ի դեպքում frame-ը ՉԻ կարող անցնել «ընդունված», ՉԻ կարող ռենդեր/հրապարակում շարունակել, ու սեփականատերը տեսնում է FAIL-ը։
