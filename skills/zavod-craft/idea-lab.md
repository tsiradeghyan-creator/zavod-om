# Idea Lab — Իդեա գեներացնող թիմի մեթոդաբանություն (Station 0)

World-class development-room craft, tuned to the Maghakian universe. Load BEFORE
pitching any new concept (post, Reel, carousel series, micro-drama, TV pitch).
Voice/themes come from `style-profile.md` + `brand-voice.md` — ideas must pass through them.

## The what-if engine (premise generation)

1. **«Ի՞նչ կլինի, եթե…»** — generate 10 what-ifs fast, no judging. Force collisions:
   ordinary Armenian life × extraordinary pressure (her formula: a vet dancer who can't
   walk; a love with a false address; a class one step from prison).
2. **Bad-version-first.** Write the cliché version on purpose, then invert one element
   (gender, era, who's lying, who pays). The Maghakian twist is usually *who carries
   the secret*.
3. **Steal from the well, not from TV.** The novel/corpus symbols (anchor, laundry line,
   saved cigarette, fish) are seed crystals — give one to a new character and ask what
   life made it precious.
4. **Comment mining.** The top comment under the last post = the next premise
   (carousel-template's CTA loop). Audience pain → premise. **Bridge step:** translate
   the raw pain INTO the universe (memory, dignity, «ապրել vs շնչել») BEFORE the brand
   test below — otherwise audience-led gold gets silently killed for being "off-brand".
5. **Transcript → premise** (feeds the [[agent-reach]] YouTube/Reddit ingest lane). Given a
   pulled transcript, generate a short-video script BY MOTIF, never verbatim:
   `hook (≤2s read) → 3 beats (one thought each) → final turn`, ≤40s, **zero verbatim
   phrases from the source**, then run the same brand + ethics gates below. Source is a
   seed crystal, not a script to copy.

## High-concept test (kill weak ideas early)

An idea survives only if ALL four pass:
- **One breath:** can it be said in one sentence with built-in irony?
  («Մարդը օվկիանոս է անցնում սիրո համար, որը գոյություն չունի»):
- **Poster test:** is there ONE image that tells it? (mask, marionette, frozen laundry).
- **Stranger test:** does someone who never saw Armenian TV stop scrolling?
- **Brand test:** does it touch the universe — «ապրել vs շնչել», memory, dignity,
  the cold heart that longs to surrender? If not, it's content, not Maghakian content.

Then refine the survivors with four craft tests:
- **Controlling idea / counter-idea (McKee):** state the value-at-stake AND the opposing
  argument the antagonist embodies. «ապրել vs շնչել» IS a controlling idea — every logline
  needs its own. (Carries into G1 below.)
- **Promise of the premise:** list 5 scenes the audience is buying a ticket for. If you
  can't, it's a logline, not a show.
- **Trope-subversion map:** name the 3 nearest clichés, mark which one she inverts. Her
  formula = **invert WHO CARRIES THE SECRET.**
- **Comp triangulation:** "X meets Y, but Z" — one comp local, one global (K-drama / dizi).
- **Structural-tension test (vertical/serial routes):** conflict must be **pre-loaded in the
  premise, not manufactured scene-by-scene** — name which tension frame carries it
  (enemies-to-lovers · forbidden proximity · power imbalance · forced circumstance). If every
  episode has to invent a new reason to fight, the premise is flat. Her layer on top: the
  frame is the chassis, **who carries the secret** is the engine inside it.
- **Character-engine test (serial routes only):** does the central relationship regenerate
  conflict for 100 episodes WITHOUT the premise resolving? (Armen⟂Anais passes; most
  what-ifs won't.) Fail = it's a film/Reel, not a serial.

## Scoring matrix (pick by numbers, not mood)

**Weight by route — a perfect single post must not be punished for not being a serial:**
- **Single post / Reel / carousel:** score /50 on hook strength (**×2**, so 2–20) · brand fit ·
  production cost (inverted) · platform fit. **≥40/50 = produce now; 30–39 = park; <30 = kill.**
- **Serial / micro-drama / TV:** add **seriality** (character-engine + 100-ep test) as a
  5th axis → score /60. **≥48/60 = produce now; 36–47 = park; <36 = kill.**
  (Thresholds are 80% = produce, 60% = park on both routes.)

Score each axis 1–10. Big bets (a new series, a pitch to a channel) → run `llm-council`.

## Writers-room protocols

- **10 → 3 → 1:** ten loglines, three hooks each for the best three, one goes to script.
- **«Այո, և…»** rounds when expanding; **devil's advocate** pass when locking
  (one voice argues the audience scrolls past — answer them in the hook).
- **Beat-storm for serials:** before episodes, list 30 *turns* (betrayals, reveals,
  collapses, doors opening). Her structure runs on turns, not plots.
- **Idea bank:** parked ideas live in this folder as `idea-<slug>.md` with their scores;
  re-score quarterly — platforms shift.

## Format router (where the idea should live)

| Signal | Route |
|---|---|
| One emotion, one image | Single post / Reel (4-station pipeline) |
| A list, a process, facts | Carousel (`carousel-template.md`) |
| A character voice that won't shut up | Insta-serial (`mini-scenario` skill) |
| A world + 30 turns | Vertical micro-drama, 60–100×1–2min (FILM MODE, `serial-structure.md`) |
| A channel/buyer in mind | TV pitch (`producer-craft.md` deck anatomy) |

## Development gates (idea → greenlight)

G1 logline + **controlling idea/counter-idea** locked → G2 one-pager (world, 3 characters,
season arc, comps) → G3 pilot beats (the first 3 turns) — each beat must chain by
**"but / therefore," never "and then"** (Parker/Stone causality test) → G4 proof-of-concept
(AI-prototyped teaser via `cinematography.md` prompt tables + fal-ai) → greenlight. Never
skip G4 for big bets: a near-zero-cost AI sizzle (render credits only, not $0) kills or
proves an idea in a day. Structure work
(season grid, cliffhanger menu, plant/payoff bible) lives in `serial-structure.md`.

## Ethics gate (non-negotiable)

War / blockade / Artsakh / illness / real-trauma premises pass a **dignity-not-exploitation
check** before production: is the pain rendered with restraint and respect (her register),
or mined for engagement? If it's the latter, it dies here. (`brand-voice.md` — earn it.)
