# Auto-Verification Loop — Ինքնաստուգվող համակարգ (ԱՎՏՈՆՈՄ ռեժիմ, պարտադիր)

> Ինչո՞ւ էր պետք. «Վան» նախագծում նույն արատը (կրկնակ կերպար, ուսուցչի drift) անցավ **երկու անգամ**,
> որովհետև QC-ն հենվում էր մարդկային «հպանցիկ հայացքի» վրա։ Ավտոնոմ նախագիծ վարելու համար
> հայացքը ԱՐԳԵԼՎՈՒՄ Է որպես ստուգման մեթոդ։ Փոխարենը՝ 5 սյունով ինքնաստուգում։

## Սկզբունք. կանխել > բռնել > կրկնել, և ՈՉ ՄԵԿԻ վրա չվստահել

### Սյուն 1 — Կանխում աղբյուրում (generation contract)
Ամեն frame-ի համար նախ գրվում է **Acceptance Manifest** (մեքենա-ստուգելի).
```
frame: S__
expected_characters: {Van:1, Hayk:1, teacher:1, Nane:1, extras:N}   # ՃՇԳՐԻՏ քանակ
canonical_refs: [van#11111, hayk#22222, teacher#44444, ...]
forbidden: "no second Van; no duplicate of any named character"
beat: "<սցենարի այս կադրի տողը>"
method: empty-plate + single-instance (բնակեցված-master reframe ԱՐԳԵԼՎԱԾ)
```
Render-prompt-ը ԳՐՎՈՒՄ Է manifest-ից, ոչ ազատ ձևով։

### Սյուն 2 — Անկախ, հակառակորդ վերիֆիկատոր (generator ≠ verifier)
Ռենդերից հետո **առանձին** vision-անցում, որի **խնդիրն է FAIL գտնել**, ոչ հաստատել։
Պարտադիր **ստրուկտուրացված թվարկում** (ոչ «լավ տեսք ունի»).
```
Q1 (COUNT): «Թվարկի՛ր ԱՄԵՆ մարդ կադրում — դիրք + հագուստ + մազ։ Քանի՞ գանգուր
            մանուշակ-սվիտերով տղա կա։ Քանի՞ բորդո-հուդիով։ Քանի՞ տարեց ուսուցիչ։»
Q2 (IDENTITY): «Ամեն անվանված կերպարի դեմքը նո՞ւյնն է, ինչ կանոնական պորտրետը (yes/no + ինչու)։»
Q3 (BEAT): «Կադրը ցույց տալի՞ս է հենց այս բիթը՝ "<beat>" (yes/no)։»
Q4 (RULES): «Հայերեն տեքստ կա՞ կադրում։ Պատահական/սխալ դեմք կա՞։»
```
**FAIL պայման (ավտոմատ).** ցանկացած named character-ի count ≠ manifest · identity=no · beat=no · տեքստ=yes։

### Սյուն 3 — Կոշտ դարպաս (hard gate)
FAIL → frame-ը **ՉԻ** դառնում «ընդունված», **ՉԻ** շարունակում ռենդեր/մոնտաժ/հրապարակում։ Բացառություն չկա։

### Սյուն 4 — Սահմանափակ ինքնա-կրկնում (bounded auto-retake)
FAIL-ի դեպքում՝ **retake, ոչ reroll** — նոր prompt, որ ուղիղ հակադրվում է named fault-ին
(«remove the second Van»; «teacher must match canonical #44444»)։ Առավելագույնը **2 retake**։
Դեռ FAIL → **escalate to owner** (չի կախվում լուռ)։

### Սյուն 5 — Ինքնաշարժ ledger + գովազդ չանել
Ամեն frame-ի verdict (PASS/FAIL + Q1–Q4 պատասխանները) ավտոմատ գրվում է log-ում։
Agent Report-ի պարտադիր տող՝ `QC-Auto: PASS k/N · FAIL m/N (escalated: …)`։

## Ոսկե կանոն
**Երբեք մի՛ ասա «կարգին է» առանց Q1-ի թվարկման։** «Աչքով լավ տեսք ունի» = ոչ-ստուգում։
Ֆոնը միշտ խոշորացրու․ արատը գրեթե միշտ ֆոնում է (կրկնակ կերպար, drift- ուսուցիչ)։
